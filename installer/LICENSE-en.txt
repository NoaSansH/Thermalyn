LOW-LEVEL ACCESS

Thermalyn reads hardware sensors. Processor temperature and power draw are not
published by Windows: they require direct access to the processor registers.
That access goes through PawnIO, a signed open-source driver, which this
installer offers to install when it is missing.

The application starts with administrator rights for the same reason. It runs
entirely offline and sends no data anywhere.
